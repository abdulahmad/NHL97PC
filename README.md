# NHL 97 for DOS

> **🤝 Making a mod, hack, port or other derivative work from this repo? You must credit me and everyone credited in this repo, clearly, in your own repo and in every release. See [Credits and derivative works](#credits-and-derivative-works).**

> **📀 Bring your own game files.** This repo holds no game files. `./build.sh` needs your own NHL 97 `HOCKEY.EXE` (in `retail/`,
> or `NHL97_EXE=/path/to/HOCKEY.EXE`); it checks the SHA-1 and size and tells you what it needs when the file is missing.

## 🚧 Current Status

- **The whole EXE builds from NASM source, byte-identical** (`./build.sh` prints MATCH), with a label for every address and the LE
  fixup tables regenerated by the linker. Only the Watcom stub and the LE header fields are taken from your EXE. The tools and
  layout are [NHL96PC](https://github.com/abdulahmad/NHL96PC)'s and [NHL95PC](https://github.com/abdulahmad/NHL95PC)'s.
- 137 code files (`src/engine`, `src/front`, `src/lib`) and 162 data files, in the NHL95PC/NHL96PC clean-up style: no
  per-line addresses, local jump labels, a header on every routine. Module boundaries are provisional (`segmap97pc.json`):
  97 is largely a new engine, so most game files are still placeholders named by address.
- Names: 280 library names (FLIRT) and 189 from NHL96PC / NHL95PC where the code matches. Naming the rest is the work in
  progress (94 Genesis / SNES names first, then 95/96 PC).
- **SDL2 port on [Overbar](https://github.com/abdulahmad/overbar)** in `port/` (NHL96PC's host, retargeted to 97):
  `make sdl2-win` builds `build/win/hockey97-win32.exe`. Not yet run on screen. See [docs/SDL2_PORT.md](docs/SDL2_PORT.md).
- This is a **disassembly only**: labelled 32-bit x86 assembly that reassembles byte-identical. There is no C decompilation.

## Build

Needs NASM 2.15+ and Python 3. `./build.sh` ends with `MATCH: build/HOCKEY.EXE is byte-identical to the retail HOCKEY.EXE`. See
[docs/ASM_BUILD.md](docs/ASM_BUILD.md).

`./build.sh 11` builds patch 1.1 (HOCKEY.EXE 1,871,324 bytes, SHA-1 `dadba8ec9aeb111f044ca2457736447ef2929809`) from the
same source: `MATCH: build/v11/HOCKEY.EXE is byte-identical to the patch 1.1 HOCKEY.EXE`. See [docs/ASM_BUILD.md](docs/ASM_BUILD.md#patch-11).

## Lineage

NHL 97 PC follows [NHL96PC](https://github.com/abdulahmad/NHL96PC) and [NHL95PC](https://github.com/abdulahmad/NHL95PC). Names
come from the earlier games, matched by purpose: a name from NHL 94 Genesis / SNES or an earlier game wins, then NHL 95 PC / 96 PC;
a 97-only name is used only when no earlier game has the routine.
